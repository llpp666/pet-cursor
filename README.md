# 🐛 小虫光标 · Pet Cursor

把 Windows 里那个千篇一律的三角形鼠标箭头，换成蝴蝶、蜜蜂、猫、狐狸……想换哪个点哪个。
内置 40 个昆虫 / 动物 / 奇幻图标，可自由选择。

## 两种运行方式

| 入口 | 特点 |
| --- | --- |
| **`启动工具.bat`** → `发布\小虫光标\小虫光标.exe` | **独立桌面软件**（推荐）：双击即开独立窗口，无需 Python 环境，可整个文件夹拷到别的电脑直接用，内置 AI 抠图引擎 |
| **`启动工具(AI抠图版).bat`** | 源码运行方式，需要本机 Python；优先使用 rembg 的本机模型 |

窗口模式：优先用 Chrome / Edge 的应用模式打开（无地址栏，像原生软件）；
用户上传的图片保存在 exe 同级的 `user_icons/` 目录。

## 怎么用

双击 **`启动工具.bat`**，会自动打开软件窗口（底层服务 `http://127.0.0.1:8899`）：

1. 在图标墙里点一个喜欢的（**鼠标悬停在卡片上就能预览真实指针效果**）
2. **点一下图标 → 弹出「调整图案大小」面板**：拖动滑块（或点 ＋ / −）可把动物在光标里放大缩小（30%~250%），左侧大图实时更新，鼠标移到大图上还能看到真实大小的实际指针；调到满意再点「应用为我的鼠标」
3. 其他可调设置：**箭头尖**（白色三角标出真正的点击位置，推荐开）、**箭头尖颜色**（10 个预设色 + 自定义取色器，描边自动取对比色）、**图案大小**（与上面的滑块联动）、光标尺寸（32 / 48 / 64 / 96 / 128 / 192 / 256 px）、点击热点位置、要替换哪些鼠标状态
   - 说明：滑块超过 100% 会同步放大实际光标画布，例如 64px × 250% 会生成 160px 光标；Windows 上限为 256 × 256
3. 点「恢复系统默认箭头」一键还原

关闭命令行窗口即退出工具，光标设置会保留（重启电脑也还在）。

## 用我自己的图片

页面上有「用我自己的图片当箭头」区域：**点击选择**或**直接把图片拖进去**（支持多选）。
PNG / JPG / GIF / WebP 都行。长图（如手机竖拍照片）默认**完整保留**不裁剪，
也可在上传区切换成「居中裁成正方形」。透明背景的图效果最好。

上传后会出现在图标墙的「我的图片」分类里，跟内置图标一样使用（悬停可预览、点一下就应用）。

**上传时先选归属地**（之后也能随时互转）：

| 分区 | 谁能用 | 存在哪 |
| --- | --- | --- |
| 🔒 私人区（默认） | 只有这台电脑上的自己，拷软件时不会被带走 | `%LOCALAPPDATA%\PetCursor\private_icons\` |
| 👥 公共区 | 拿到这个软件的人都能用 | 程序目录 `user_icons/`，随文件夹一起被拷走 |

卡片左上角有 👥公共 / 🔒私人 标签；右上角按钮可**互转分区 / ✂ 抠图 / × 删除**（删除有二次确认）。抠图结果沿用原图分区。

## AI 智能抠图

带杂乱背景的照片 / 截图不用自己处理：

- 上传区有开关 **「上传后自动抠图」**，勾上后每张图上传完自动去背景
- 也可以不勾，之后把鼠标移到自定义卡片右上角点 **✂** 单独抠图
- 抠图会生成一个新图标（名字带「·抠图」），**原图保留**，可以对比着选
- `.exe` 内置本地 ONNX Runtime + 轻量 U²-Net 模型，不需要安装 Python，不会上传图片，
  第一次打开也能完全离线使用
- 源码方式会优先复用本机 rembg 模型；若本机已有高质量模型，打包版也会优先复用
- 万一 AI 引擎不可用，会自动退回「取边去背景」的简易算法

## 无需登录

打开就能用，没有账号系统：公共区、私人区都能直接上传和使用。

- 服务只监听 `127.0.0.1`，同一 WiFi 里的其他设备访问不到、改不了鼠标
- 图片全部只存在本机（`%LOCALAPPDATA%\PetCursor\`），不上传任何服务器
- 旧版本按账号分目录的私人图片，服务启动时会自动合并回统一私人区

## 光标守护（右键闪默认箭头的修复）

Windows 弹右键菜单、重启资源管理器、UAC 弹窗时会临时把光标切到别的状态
（后台运行 / 忙等）——那些状态没被替换就会闪一下默认箭头。两层修复：

1. 应用时**默认替换全部 15 种鼠标状态**（可点"只留常用 2 种"退回旧行为）；
2. `cursor_tools.py` 内置**守护线程**：每 1.5 秒比对注册表，发现被改回默认就立刻
   重写并广播 `SPI_SETCURSORS`。状态存 `guard.json`，"恢复默认"会自动停守护。
   可选「开机自动守护」：在启动文件夹放一个指向 `--guard-only` 模式的快捷方式
   （`app.py --guard-only`：不启服务不开窗口，纯后台守护）。

## 🦋 小蝴蝶编号

`butterfly.py`：零服务器的"下载人数"。编号计数器存**软件文件夹**
（`小蝴蝶编号.json`，随文件夹传播），本机领取的号固定存 `%LOCALAPPDATA%\PetCursor\install.json`。
同一台电脑永远同一个号；软件被拷到新电脑第一次运行时 +1。全程离线。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `butterfly.py` | 🦋 小蝴蝶编号（离线下载计数） |
| `启动工具.bat` | 启动打包好的桌面软件（exe）；没有 exe 时退回 Python 方式 |
| `启动工具(AI抠图版).bat` | Python 方式启动，带 AI 抠图 |
| `app.py` | 桌面外壳：内置服务 + 独立窗口（`--server-only` / `--guard-only`） |
| `build_exe.py` | PyInstaller 打包脚本，产物在 `发布\小虫光标\` |
| `server.py` | 本地服务 + 上传/应用/恢复接口；只监听 127.0.0.1 |
| `cursor_tools.py` | PNG → `.cur` 生成、注册表写入、备份恢复、光标守护 |
| `download_icons.py` | 从 OpenMoji / Twemoji CDN 拉取图标，生成 `catalog.json` |
| `web/index.html` | 图形界面 |
| `icons/` | 内置图标原图（618px PNG） |
| `catalog.json` | 内置图标清单（增删改图标后重新跑下载脚本即可） |
| `user_icons/` | 你自己上传的图标 + 清单 |

## 原理

- 用 Pillow 把 PNG 缩放后写成 ICO 二进制，再把文件头 `type` 由 1 改成 2（变成 `.cur`），
  并把 `wPlanes / wBitCount` 字段改写为**热点坐标**。
- 写入 `HKEY_CURRENT_USER\Control Panel\Cursors` 相应键值，
  再调用 `SystemParametersInfoW(SPI_SETCURSORS)` 广播，光标立即生效，无需注销。
- 首次应用会自动备份原设置到 `%LOCALAPPDATA%\PetCursor\backup.json`。
- 生成的 `.cur` 放在 `%LOCALAPPDATA%\PetCursor\cursors\`，**不要删这个目录**。

## 加更多图标

编辑 `download_icons.py` 里的 `ITEMS` 列表，加一行 `(码位, 中文名, emoji, 分类)`，
然后运行 `python download_icons.py`，重启工具即可（界面上的分类会自动出现）。

## 开源说明

### 隐私：这个软件不联网传你的图

- **只监听本机 `127.0.0.1`**，局域网里的其他设备访问不到
- 你上传的图片**永远只存在这台电脑上**，不会上传到任何服务器
- 唯一的网络请求是下面说的「社区图标库」**下载**，而且是只读的
- 想确认的话，把网线拔了照样能正常用（只是拉不到新图标）

### 公共区 / 私人区到底是怎么回事

| 分区 | 谁能看到 | 存在哪 |
| --- | --- | --- |
| 🔒 私人区 | 这台电脑、这个 Windows 账户 | `%LOCALAPPDATA%\PetCursor\private_icons\` |
| 👥 公共区 | 拿到这个软件文件夹的人 | 程序目录 `user_icons/` |
| 🌐 社区库 | 所有使用者（只读，从 GitHub 拉） | `%LOCALAPPDATA%\PetCursor\community\` |

**没有服务器、没有账号、没有登录** —— 这是刻意的设计。
「私人」的边界是**这台电脑的这个 Windows 账户**，不是「你这个人的身份」：
能坐到你电脑前、登你 Windows 账户的人，就看得见你的私人图片。
如果你需要真正的隐私保护，给私人区加一个本地口令锁就够了（不需要服务器，存密码哈希即可）。

至于「让陌生人看到我上传的图」—— 那是社区广场，必须有服务器和账号体系，
这个项目不提供，也不打算提供。

### 社区图标库（可选）

图标库就是仓库里的 `catalog.json` + `icons/`，**谁都能提 PR 加图标**。
软件启动时可以自动从 GitHub 拉最新的图标清单，只下载、不上传。

启用方法：把 `community.example.json` 复制成 `community.json`，填你的仓库：

```json
{ "repo": "你的用户名/仓库名", "branch": "main" }
```

- 走 jsDelivr 分发（`fastly` 节点，`cdn` 节点在国内常被掐断）
- 拉不到网就**静默降级**到软件内置的 40 个图标，离线完全可用
- 只在 `version` 字段变化时才真正下载，不会每次启动都拉一遍
- `repo` 留空 = 关闭这个功能

### 从源码运行

```bash
pip install Pillow
python server.py          # 浏览器打开 http://127.0.0.1:8899
```

想用 AI 抠图再装（会自动下载约 170MB 模型，装不上就回退简易去背景）：

```bash
pip install "rembg[cpu]"
```

### 打包成 exe

```bash
pip install pyinstaller
pyinstaller 小虫光标.spec
```

产物在 `dist/小虫光标/`，整个文件夹拷到别的电脑就能直接用。
