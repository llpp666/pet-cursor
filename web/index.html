图案/光标放大 100%
· 左右拖动滑块（或点 ＋ / −）实时看效果，调到喜欢的大小再点“应用”。
· 上面的大图是放大展示；把鼠标移到大图上，还能看到真实大小的实际指针。
· 白色箭头尖画在图案后面，只会露出尖角指出点击位置，不会挡住图标； 调大小不会改变点击位置。
· 想要更大？把上面设置区的「光标尺寸」换成 96 / 128 / 192 / 256； 滑块超过 100% 也会同步放大实际光标（例如 64 × 250% = 160），最大为 256 × 256。
· 关于上限：Windows 的光标文件最大就是 256 × 256，再大系统不认， 所以做不到“半个屏幕”那么夸张；如果换成大尺寸后屏幕上没变化， 说明 Windows 按自己的指针大小在缩放显示 —— 去 设置 → 蓝牙和设备 → 鼠标 → 鼠标指针（或控制面板「鼠标 → 指针」） 把指针大小调大即可。
把鼠标移到这里 → 悬停任意图标即可预览真实指针（白色箭头尖的位置 = 真正点击的位置）

读取守护状态…
· 光标守护：开着时，一旦 Windows 把光标改回默认（右键菜单、资源管理器重启、UAC 弹窗都会）， 会在 1~2 秒内自动换回你的图标；关掉软件后守护也停，想一直守着就开“开机自动守护”。
· 应用后光标立即生效；个别已打开的程序需要鼠标划过或重新激活窗口才刷新。
· 首次应用会自动备份你原来的光标设置，点“恢复系统默认箭头”即可还原。
· 光标文件保存在 ，请勿删除该目录，否则重启后光标会失效。
